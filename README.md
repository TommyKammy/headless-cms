# Headless CMS

A simple headless CMS system for website creation.

## Overview

This is a lightweight headless content management system designed for building websites with a clean API-first approach.

## Features

- Content type definitions
- RESTful API
- Media management
- User authentication
- Role-based access control

## Getting Started

```bash
npm install
npm run dev
```

## API Endpoints

- `GET /api/content` - List content
- `POST /api/content` - Create content
- `GET /api/content/:id` - Get single content
- `PUT /api/content/:id` - Update content
- `DELETE /api/content/:id` - Delete content
